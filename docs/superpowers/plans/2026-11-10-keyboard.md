# Управление с клавиатуры, как в lazygit — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** цифры `1`–`4`/`0` переводят фокус между областями панели и вкладкой «Diff», `f` сворачивает область, `/` ищет, видимые кнопки — по первой букве, `?` — подсказка, тонкая линия слева у выбранной области.

**Architecture:** чистая таблица клавиш (`src/ui/keys.ts`) + DOM-диспетчер панели (`src/ui/panelkeys.ts`), которому `app.ts` отдаёт области и действия; вкладка «Diff» ищет свои клавиши в той же таблице. Воркер получает запрос `diff.focus`: показать вкладку без перезагрузки.

**Tech Stack:** TypeScript без сборки (Орка транспилирует), DOM, `orca/testing` + `node:test` для тестов, headless Chromium для DOM-проверок.

**Spec:** `docs/superpowers/specs/2026-11-10-keyboard-design.md` (читать вместе с планом).

## Global Constraints

- Клавиши сравниваются по `event.code` (`KeyU`, `Digit1`, `Slash`, `Period`), а не по `event.key`: `u` работает и в русской раскладке.
- Событие с Ctrl, Alt или Meta не трогается; Shift — только у записей с `shift: true` (`?` = `Shift+Slash`, Fetch = `Shift+KeyF`).
- Не трогать событие, если `defaultPrevented`, если цель в `input, textarea, select, [contenteditable], .overlay, .menu, .popover`, и пока на странице есть `.busy` (оверлей `busy`, `src/ui/dialogs.ts:365`).
- Ни одна клавиша не меняет репозиторий; Fetch — как кнопка Fetch.
- Старые сочетания не меняются: стрелки, Page Up/Down, Home/End, Ctrl+A, Ctrl+C, Shift+F10, Enter, Space, F7, ← → и Alt+↑/↓ во вкладке.
- Все строки интерфейса — через `t()`, в `en` и `ru` (`src/shared/i18n.ts`; у `ru` тип `Record<keyof typeof en, Message>`, пропуск ключа — ошибка типов).
- Исходники в `src/` — с концами строк CRLF (`git ls-files --eol`), новые файлы в `src/` — тоже CRLF; правка не меняет концы нетронутых строк. Документы в `docs/` — LF.
- Ошибок типов не больше базы: `npx -y -p typescript@5 tsc -p . --noEmit` — 107 на коммите `90e8a02`; в новых и изменённых файлах — 0. `findLastIndex` и другие ES2023 нельзя (нет в lib проекта).
- Тесты: `orca plugin test .` — все зелёные (178 на `90e8a02`).

## Review Focus

1. Буква в поле поиска или в открытом окне фильтра печатается, а не срабатывает (тест: Task 4, «letters in a field type»).
2. Esc в непустом поиске коммитов только очищает поле и не уводит фокус (Task 4, «Esc in a search with text stays»).
3. `f` на последней открытой области ничего не делает и не теряет фокус (Task 4, «f on the last open area»).
4. `0` при уже открытой вкладке не сбрасывает её прокрутку: воркер не шлёт `diff.show` (Task 3, тест `diff.focus`).
5. Пока стоит оверлей `busy`, клавиши не работают (Task 4, «busy blocks keys»).

Значения таблицы (из дизайна, раздел «Клавиши»):

| search | Slash | | anywhere | keySearch | / |

| matchCase | KeyC | | commits | matchCaseTip | c |
| expandAll / collapseAll | KeyE / KeyC | | files | expandAll / collapseAll | e / c |

### Task 4: Диспетчер клавиш панели

**Files:**
- Create: `src/ui/panelkeys.ts`

**Interfaces:**
- Consumes: `findKey`, `KeyId`, `KeyScope` (Task 2); `SectionId` (`sections.ts`).
- Produces:
  ```ts
  export interface PanelArea {
    root: HTMLElement        // секция, `data-section`
    body: HTMLElement        // тело секции; получает tabindex="-1"
    toggle: HTMLElement      // кнопка sec-toggle
    target(): HTMLElement | null   // куда ставить фокус по цифре; null → body
    search?: HTMLInputElement
  }
  export interface PanelKeysHost {
    areas: Record<SectionId, PanelArea>
    isOpen(id: SectionId): boolean
    toggle(id: SectionId): void    // как клик по заголовку; последнюю открытую не сворачивает
    run: Partial<Record<KeyId, () => void>>
  }
  export function mountPanelKeys(host: PanelKeysHost): void
  ```
- Поведение (дизайн, «Поведение»): текущая область — секция с фокусом, иначе последняя; класс `current-area` на её `root` ставится по `focusin` и снимается только при переходе в другую область. Цифра: развернуть, если свёрнута, и фокус в `target() ?? body`. `fold`: `toggle(id)`; если `isOpen` изменился — фокус на `toggle`. `search`: есть `search` → развернуть, `focus()`, `select()`; нет — ничего. Буква области: развернуть, затем `run[id]`. Esc в `search` с пустым значением → фокус в `target() ?? body` (Esc с текстом обрабатывает само поле и вызывает `preventDefault`). Остальные `anywhere` — `run[id]`. Нет текущей области — работают только `area*`, `diff`, `refresh`, `fetch`, `help`. Обработанное событие — `preventDefault()`. Ограничения из Global Constraints — здесь.
- CSS: `.col-section.current-area { box-shadow: inset 2px 0 0 var(--ring); }` (или псевдоэлемент — на выбор исполнителя; без сдвига содержимого).

  - `digits move focus and open a folded area` — `Digit3` при свёрнутой files → `isOpen('files')`, фокус на `target()`; `current-area` у files.
  - `f on the last open area` — свернуть всё, кроме commits, `KeyF` в commits → область открыта, фокус на месте.
  - `f folds and focuses the toggle` — `KeyF` в files → свёрнута, `document.activeElement === toggle`; `KeyF` ещё раз → открыта.
  - `slash searches only where a field is` — `Slash` в commits → фокус в поле, текст выделен; в files → фокус не сдвинулся.
  - `letters in a field type` — фокус в поле, `KeyU` → `run.filterUser` не вызван, `defaultPrevented === false`.

  - `modifiers pass` — `ctrlKey` + `Digit1` → ничего.
  - `the area line stays when focus leaves` — фокус на элемент вне секций → `current-area` остался у последней.
